# Chat UI Project

## Description

This project is a modern Chat User Interface built using HTML, CSS, JavaScript, jQuery, and Bootstrap 5.
It simulates a chatbot similar to ChatGPT with features like message display, typing indicator, suggestion cards, sidebar options, and responsive design.

## Features

* User and AI chat interface
* Suggestion cards for quick actions
* Typing indicator animation
* Auto-resizing input box
* Sidebar with New Chat, Dark Mode, Export Chat
* Responsive design (mobile, tablet, desktop)
* Clean UI with smooth animations

## How to Run

1. Download or extract the project folder
2. Open the folder
3. Double-click on `index.html`
4. The chat UI will open in your browser
5. Start using the application

## Technologies Used

* HTML5
* CSS3
* JavaScript
* jQuery
* Bootstrap 5
